Project 03

NightWatch 야간 자율순찰 시스템

자율주행 로봇이 야간 순찰을 수행하며 이상상황 탐지와 GPT 기반 관제 리포트를 자동화하는 시스템입니다.

2026.03 ~ 04 ROS2 YOLO11n GPT-4o FastAPI

프로젝트 개요

자율주행 로봇이 야간 순찰을 수행하며 실시간으로 이상상황을 탐지하고, GPT-4o 기반 상황 보고서를 자동 생성하여 보안 인력의 효율적 배치를 지원하는 시스템입니다.

주요 성과

  • 시스템 평균 응답 시간 3.1초 달성
  • 탐지, 위치 추정, 보고서 생성, 알림까지 이어지는 통합 흐름 구현
  • 데이터 증강과 최적화를 통해 실용적인 탐지 성능 확보

주요 문제 해결 사례

문제 1. 시스템 통합 구동 시 하드웨어 과부하 및 지연

해결: YOLO 추론을 별도 프로세스로 분리하고 5Hz로 제한했으며, Nav2는 별도 스레드에서 실행해 부하를 분산했습니다.

결과: CPU 사용률을 85%에서 62%로 낮추고 프레임 누락을 크게 개선했습니다.

문제 2. sim_time과 wall_time 불일치로 인한 Transform 실패

해결: use_sim_time 전역 설정과 TF2 Buffer 캐시 타임 10초 확장을 적용했습니다.

결과: Transform 조회 성공률 100%를 달성했습니다.

문제 3. 단일 환경 통합 실행 시 병목 및 동기화 오류

해결: ROS/Gazebo는 sim_time 기준으로 동기화하고 Vision AI는 독립 프로세스로 분리했습니다.

결과: 컴포넌트 간 간섭을 줄이고 통합 서버 환경에서 안정적으로 실행했습니다.

담당 업무 및 사용 기술

  • ROS2 + Nav2 기반 SLAM, Localization, Path Planning 및 Gazebo 시뮬레이션
  • YOLO11n 탐지 모델과 EfficientNet-B0 상태 분류 파이프라인 개발
  • 카메라 픽셀 좌표를 map 좌표계로 변환하는 TF2 기반 위치 추정 알고리즘 개발
  • FastAPI/Flask REST API로 ROS와 웹을 통합하고 React에서 로봇 상태 표시
