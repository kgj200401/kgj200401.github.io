Project 02

지능형 스마트팜 통합 관리 솔루션

Edge-Cloud 하이브리드 구조로 병해 탐지와 RAG 기반 리포트 생성을 연결한 스마트팜 관리 시스템입니다.

2026.01 ~ 02 MEERUSFARM YOLOv8 Nano TensorRT LLM RAG

프로젝트 개요

숙련공 부족 문제를 해결하기 위해 AI와 IoT 기술을 융합했습니다. 비전문가도 현장을 빠르게 파악하고 의사결정할 수 있도록 실시간 탐지, 센서 데이터, 지식 기반 리포트를 하나의 흐름으로 구성했습니다.

주요 성과

  • 실시간 탐지 정확도 mAP50 0.9 달성
  • Polygon 라벨링 기반 파인튜닝으로 손실값 18% 감소
  • 프로젝트 마감 시간 준수와 안정적인 MVP 완성

주요 문제 해결 사례

문제 1. 최신 기술 도입 리스크와 데드라인 상충

해결: vLLM 통합 리스크를 빠르게 판단하고, 안정적인 모델 파이프라인과 프롬프트 엔지니어링 기반 지식베이스로 우회했습니다.

결과: 사용자 경험 수준을 유지하면서 일정 내 서비스 런칭을 달성했습니다.

문제 2. 팀 내 개발 방향 차이

해결: 핵심 기능을 먼저 선정하고 단계별로 고도화하는 개발 로직을 제안했습니다.

결과: 팀 내 합의를 이끌어내고 일관된 개발 방향으로 MVP를 완성했습니다.

담당 업무 및 사용 기술

  • AI 모델 파이프라인 총괄 및 Detection/Segmentation 최적화
  • 1,248개 Polygon 라벨링 데이터 제작 및 파인튜닝
  • 센서 데이터와 농업 지식 베이스를 결합한 RAG 시스템 설계
  • LLM을 활용한 농작물 상태 분석 리포트 자동 생성 기능 구현
  • Jira 기반 Agile Sprint 운영 및 백로그 우선순위 관리
  • 영상 포토폴리오 제작 및 성과발표
