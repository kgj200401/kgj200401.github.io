이미지 기반 VQA 멀티모달 AI 모델

2025.10 ~ 2025.10

📌 프로젝트 개요

제한된 인프라 자원을 극복하여 대규모 모델의 비즈니스 활용 가능성을 검토하고, 최적화 기법을 통해 운영 효율성을 확보하는 것을 목표로 하였습니다.

🏆 성과 및 문제 해결

  • VRAM 70% 절감: Unsloth 기반 4bit 양자화(Quantization)와 비전 레이어 프리징 및 언어 모델 LoRA 적용으로 24GB → 7GB로 사용량 대폭 감소.
  • 정확도 4.8% 향상: 데이터 분석(EDA)을 통해 Position Bias를 발견, '선지 셔플(Choice Shuffle)' 알고리즘 구현으로 리더보드 점수 0.92 → 0.9645 향상.
  • 최종 리더보드 11위 달성.

💻 담당 업무 및 사용 기술

  • 모델 성능 비교 분석 및 벤치마킹
  • 정확도 방어를 위한 하이퍼파라미터 최적값 탐색
  • Few-shot 프롬프팅 및 정규표현식 기반 출력 정형화 제어
Qwen3-VL (32B) PyTorch Unsloth LoRA/QLoRA

지능형 스마트팜 통합 관리 솔루션 (MEERUSFARM)

2026.01 ~ 2026.02 (6주)

📌 프로젝트 개요

숙련공 부족 문제를 해결하기 위해 AI와 IoT 기술을 융합하여, 비전문가도 현장을 즉시 관리할 수 있는 지능형 의사결정 보조 시스템(Edge-Cloud 하이브리드)을 구축했습니다.

🏆 성과 및 문제 해결

  • 실시간 탐지 정확도: YOLOv8 Nano + TensorRT(FP16) 최적화로 Jetson 환경에서 실시간 추론 달성 (mAP50 0.9).
  • 기술적 리스크 관리: vLLM 도입 시 기술적 제약(시뮬레이션 환경 통합 어려움)을 파악하고, 기존 파이프라인 유지 및 프롬프트 엔지니어링으로 우회하여 프로젝트 마감 기한 100% 준수.
  • 팀 내 개발 로직(MVP 우선) 제시를 통한 갈등 중재 및 성공적 런칭.

💻 담당 업무 및 사용 기술

  • AI 모델 파이프라인 총괄 (Detection/Segmentation) 설계 및 최적화
  • 1,248개 Polygon 라벨링 데이터 직접 제작 및 파인튜닝
  • 센서 데이터와 농업 지식 베이스를 결합한 RAG 시스템 설계
  • Jira 기반 Agile Sprint 운영 및 백로그 우선순위 관리 (리딩)

NightWatch - AI 기반 야간 자율순찰 시스템

2026.03 ~ 2026.04

📌 프로젝트 개요

자율주행 로봇이 야간 순찰을 수행하며 실시간으로 이상상황 탐지 및 GPT-4o 기반 상황 보고서를 자동 생성하여 보안 인력의 효율적 배치를 지원하는 시스템입니다.

🏆 성과 및 문제 해결

  • CPU 부하 및 지연 개선: YOLO 추론을 별도 프로세스로 분리(5Hz 제한)하여 CPU 사용률 85% → 62% 감소, 프레임 누락 99% 개선.
  • 좌표 동기화 해결: 시뮬레이션 시간(sim_time) 불일치로 인한 TF2 조회 실패를 캐시 타임 10초 확장으로 조회 성공률 100% 달성.
  • 시스템 응답 시간 평균 3.1초 (이상 탐지 → 위치 추정 → 보고서 생성 → 알림).

💻 담당 업무 및 사용 기술

  • ROS2 + Nav2 활용 SLAM, Localization, Path Planning 및 Gazebo 시뮬레이션
  • YOLO11n(탐지) + EfficientNet-B0(상태 분류) 비전 파이프라인 개발
  • 카메라 픽셀 좌표를 map 좌표계로 변환하는 위치 추정 알고리즘(TF2) 개발
  • FastAPI/Flask 기반 REST API로 ROS-웹 통합 및 React 실시간 로봇 상태 표시
ROS2 Humble YOLO11n GPT-4o FastAPI/Flask/React
