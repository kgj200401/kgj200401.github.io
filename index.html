이미지 기반 VQA 멀티모달 AI 모델

2025.10 ~ 2025.10

📌 프로젝트 개요

제한된 인프라 자원을 극복하여 대규모 모델의 비즈니스 활용 가능성을 검토하고, 최적화 기법을 통해 운영 효율성을 확보하는 것을 목표로 하였습니다.

🏆 주요 성과

  • 최종 리더보드 순위 11위 (최고 점수: 0.9645)
  • VRAM 사용량 70% 절감 (24GB → 7GB) 및 정확도 향상 (+4.8%)

🛠️ 주요 문제 해결 사례

문제 1. 한정된 예산과 자원 내 대형 모델 구동

해결: Unsloth 기반 4bit 양자화 도입, 비전 레이어 고정(freeze) 및 언어 모델 레이어에만 LoRA 어댑터 적용.

결과: VRAM 사용량을 70% 절감하면서도 32B 모델의 고성능 추론 능력 유지.

문제 2. 단순 통계적 오류로 인한 분석 신뢰성 저하 (Position Bias)

해결: EDA를 통해 편향 발견, 데이터 로더에서 정답과 오답을 무작위로 섞는 '선지 셔플(Choice Shuffle)' 구현.

결과: 모델이 위치가 아닌 의미적 상관관계에 집중하도록 유도, 정확도 4.8% 향상 (0.92 → 0.9645).

  • 정확도 방어를 위한 하이퍼파라미터 최적값 탐색
  • Few-shot 프롬프팅 및 정규표현식 기반 출력 정형화 제어

지능형 스마트팜 통합 관리 솔루션 (MEERUSFARM)

2026.01 ~ 2026.02 (6주)

📌 프로젝트 개요

숙련공 부족 문제를 해결하기 위해 AI와 IoT 기술을 융합하여, 비전문가도 현장을 즉시 관리할 수 있는 지능형 의사결정 보조 시스템(Edge-Cloud 하이브리드)을 구축했습니다.

🏆 주요 성과

  • 실시간 탐지 정확도 (mAP50): 0.9 (YOLOv8 + TensorRT 최적화)
  • Polygon 라벨링 기반 파인튜닝으로 손실값 18% 감소
  • 프로젝트 마감 시간 100% 준수 및 서비스 안정성 달성

🛠️ 주요 문제 해결 사례

문제 1. 최신 기술(vLLM) 도입 리스크와 데드라인 상충

해결: 시뮬레이션 환경 통합의 어려움 파악 후 신속한 의사결정. 안정적 모델 파이프 유지 및 프롬프트 엔지니어링(사전 로드 지식베이스)으로 우회.

결과: 동일한 수준의 사용자 경험을 제공하며 일정 준수 및 안전한 배포(서비스 런칭) 달성.

문제 2. 팀 내 방법론(완벽함 vs 속도) 차이로 인한 갈등

해결: 핵심 기능 선정 후 고도화하는 '단계별 개발 로직'을 제시하여 목표와 방향성을 재정립.

결과: 팀 내 합의 도출 및 일관된 개발 방향 수립으로 MVP의 성공적 완성.

💻 담당 업무 및 사용 기술

  • AI 모델 파이프라인 총괄 (Detection/Segmentation) 설계 및 최적화
  • 1,248개 Polygon 라벨링 데이터 직접 제작 및 파인튜닝
  • 센서 데이터와 농업 지식 베이스를 결합한 RAG 시스템 설계
  • Jira 기반 Agile Sprint 운영 및 백로그 우선순위 관리 (리딩)

NightWatch - AI 기반 야간 자율순찰 시스템

2026.03 ~ 2026.04

📌 프로젝트 개요

자율주행 로봇이 야간 순찰을 수행하며 실시간으로 이상상황 탐지 및 GPT-4o 기반 상황 보고서를 자동 생성하여 보안 인력의 효율적 배치를 지원하는 시스템입니다.

🏆 주요 성과

  • 시스템 평균 응답 시간 3.1초 달성 (탐지 → 위치추정 → 보고서 → 알림)
  • 데이터 증강/최적화를 통한 실용적 탐지 성능 확보 (Detection 327장, Classification 700장)

🛠️ 주요 문제 해결 사례

문제 1. 시스템 통합 구동 시 하드웨어 과부하 및 지연

해결: YOLO 추론을 별도 프로세스로 분리(5Hz 제한)하고 Nav2는 별도 스레드에서 실행하여 부하 분산.

결과: CPU 사용률 85% → 62% 감소, 프레임 누락 99% 개선.

문제 2. sim_time과 wall_time 불일치로 인한 Transform 실패

해결: use_sim_time 전역 설정 및 TF2 Buffer의 캐시 타임(Cache Time) 10초 확장.

결과: Transform 조회 성공률 100% 달성.

문제 3. 단일 환경 통합 실행 시 병목 및 동기화 오류

해결: 실행 순서 조정 및 컴포넌트 분리 (ROS/Gazebo는 sim_time 기준 동기화, Vision AI는 독립 프로세스화).

결과: 컴포넌트 간 간섭 최소화, 통합 서버 환경의 안정적 실행 및 운영 노하우 확보.

💻 담당 업무 및 사용 기술

  • ROS2 + Nav2 활용 SLAM, Localization, Path Planning 및 Gazebo 시뮬레이션
  • YOLO11n(탐지) + EfficientNet-B0(상태 분류) 비전 파이프라인 개발
  • 카메라 픽셀 좌표를 map 좌표계로 변환하는 위치 추정 알고리즘(TF2) 개발
  • FastAPI/Flask 기반 REST API로 ROS-웹 통합 및 React 실시간 로봇 상태 표시
